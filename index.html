FORMA

A calm, editorial storefront for furniture and board makers. Cream surfaces, tight Manrope typography, and a homepage built from ten composable sections.

Overview

BaseDawn 16.1.1 (Online Store 2.0)
TypeManrope 400 / 500 / 600 / 700, self-hosted WOFF2 (SIL OFL)
PaletteFive cream schemes, ink text, no accent colour by default
Layout width1400px content width, 1440px max canvas
Sections10 custom home sections + Dawn defaults for product, collection, cart, search, blog, page
LocalesStorefront strings via locales/, section labels via *.schema.json

Before publishing: replace demo imagery in assets/forma-img-*.jpg with your own photography, or upload images in each section. Demo copy lives in templates/index.json.

Install

  1. Shopify admin → Online Store → Themes.
  2. Add theme → Upload zip, or push with the CLI: shopify theme push --unpublished.
  3. Open Customize, check the homepage, then publish.

Theme settings

Colours

Five schemes, all built on the same cream base. Scheme 1 is the page default, scheme 3 is used by the footer and the sale band.

Scheme 1 · #f8f6f1 Scheme 2 · #fffdf8 Scheme 3 · #111111 Scheme 4 · #efece4 Scheme 5 · #e7e3d9

Colour scheme values must stay as RGB triplets (for example 248, 246, 241). Hex values are silently ignored by Dawn's colour system.

Typography

Headings and body both use Manrope. The type scale is defined in assets/forma.css as CSS custom properties: h1 80 / h2 56 / h3 40 / h4 32 / h5 24 / h6 22, body 20 / 18 / 16 / 14.

Navigation

header-group.json carries the announcement bar, header and the main menu. The recommended menu is Home / Shop / Rooms (dropdown with the six room collections) / About / Contact.

The footer uses the footer menu: About, Shipping & returns, FAQ, Contact, Search.

Products & collections

  • The homepage product grid reads the collection picked in the section settings (default frontpage).
  • Category cards link to /collections/all until you point them at real collections.
  • Product cards expect at least three images; the theme uses the first for grids and the rest for the gallery.

Motion & performance

assets/forma-motion.js adds three effects and disables all of them under prefers-reduced-motion:

  • Intersection-based reveal with a 70 ms stagger per item
  • Parallax on the hero and about images (±20 px, 1.07 scale)
  • Hover states on cards, links and buttons

All demo images are pre-compressed to 1200 px wide, quality 82–84, and total roughly 2 MB for the whole homepage.

Changelog

1.0.5

  • Blog index uses a two-column grid with fixed image height so titles and excerpts stay above the fold
  • Product title scales down on narrow columns to avoid one-word-per-line wrapping

1.0.4

  • Hero gained a slideshow layout: full-bleed slides with per-slide copy, fade transitions, dot pagination and an adjustable overlay
  • Product row can switch between grid and scroll-snap slider, with arrows, drag scrolling and optional autoplay
  • Slideshow images load on demand so the first slide keeps the preloaded 800px crop on phones

1.0.3

  • Every section name, preset and colour option label now resolves through locale files, and the three remaining hard-coded storefront strings ("Sale", "View piece", product placeholder) moved into translations
  • Theme identity renamed to FORMA in the settings schema and preset, so the editor and store submission carry the theme name rather than the base theme name
  • Image licence register added for all shipped photography, with the one CC BY image credited and the font licence filed alongside it
  • Homepage hero preloaded with a 62 KB 800px crop for phones, cutting the LCP image from 183 KB and lifting mobile performance to 97 / desktop to 99 in Lighthouse

1.0.2

  • Demo product imagery rebuilt per SKU so each gallery shows the actual product type instead of shared stock scenes
  • About section image replaced with a workshop shot and recropped to the 4:5 column, removing the dimension mismatch
  • Footer now ships with Shop and Help menus plus a short brand blurb, so the demo store has real footer navigation
  • Hero image marked fetchpriority="high"; footer disclosure and caption colours raised to full text contrast (LCP 1.1s, accessibility 100)
  • Gift card variants switched to continue-selling so the demo card is not shown as sold out

1.0.1

  • Demo photography replaced with a brand-free, commercially usable set (CC0 / Unsplash licence)
  • Hero, about, category, gallery and favourites imagery recropped to their section ratios
  • Homepage SEO description moved into theme settings so merchants can edit it
  • Header logo set to a custom wordmark; product card imagery ratio locked to square

1.0.0

  • Initial release: ten homepage sections, five colour schemes, Manrope type scale
  • Motion layer with reduced-motion fallback
  • Demo content, policies and navigation wired for a furniture catalogue
